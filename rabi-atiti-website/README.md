# Rabi Atiti Website

This folder contains:

- The deployable website files in this folder. Upload these files to your hosting provider.
- The readable source files in `editable/` for editing in VS Code.

## Open in VS Code

Open the `rabi-atiti-website` folder in VS Code.

## GitHub upload

Create a new GitHub repository, then upload everything in this folder.

## Local preview

Use a local web server or the VS Code Live Server extension. Open `index.html` through the server rather than double-clicking it.
